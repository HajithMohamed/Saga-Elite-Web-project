PROMPT 2.1 — HeroCarousel: Add Mouse-Move Parallax Layer
────────────────────────────────────────────────────────────────────────────────

File to edit: Client-Side/src/components/landing/LandingSections.jsx
Section: HeroCarousel component (starts around line 65)

KEEP ALL EXISTING LOGIC UNCHANGED:
  State: activeIndex, paused, dropIsLive, dropIsUpcoming
  Auto-rotate logic, touch gesture handlers
  Three conditional render states (live drop / upcoming / slideshow)

ADD mouse-move parallax to the slideshow state only (the last return — the
main carousel). This state has a section tag with the parallax image inside.

ADD to HeroCarousel component:
  const [mouseOffset, setMouseOffset] = useState({ x: 0, y: 0 })
  const sectionRef = useRef(null)

  const handleMouseMove = (e) => {
    const rect = sectionRef.current?.getBoundingClientRect()
    if (!rect) return
    const cx = rect.left + rect.width / 2
    const cy = rect.top + rect.height / 2
    setMouseOffset({
      x: ((e.clientX - cx) / rect.width) * 14,   // ±14px horizontal
      y: ((e.clientY - cy) / rect.height) * 8,    // ±8px vertical
    })
  }

  const handleMouseLeave = () => setMouseOffset({ x: 0, y: 0 })

In the slideshow return, add to the <section> tag:
  ref={sectionRef}
  onMouseMove={handleMouseMove}
  onMouseLeave={handleMouseLeave}

In the hero image wrapper div (the one with the <img> tag), add:
  style={{
    transform: `translate(${mouseOffset.x}px, ${mouseOffset.y}px)`,
    transition: 'transform 0.4s cubic-bezier(0.22, 1, 0.36, 1)',
    willChange: 'transform',
  }}

This makes the image layer gently drift with mouse movement, creating a
parallax depth effect. The transition duration keeps it smooth and luxurious.
