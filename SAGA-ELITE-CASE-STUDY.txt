1. EXECUTIVE SUMMARY
================================================================================

Saga Elite is a bespoke MERN-stack ecommerce platform for a Sri Lankan luxury
streetwear brand. It sells limited-edition "drops" alongside an always-on
catalog, with manual bank-transfer payments (PayHere available as a fallback)
and Sri Lanka-only delivery. The brand identity leans editorial — Cinzel +
Playfair Display headlines, JetBrains Mono numerics, a black/gold palette
(#0a0a0a / #f2ca50), and heavy use of Framer Motion for cinematic transitions.

By the numbers:
  - 28 admin pages across 7 sidebar sections
  - 10 fine-grained permission flags + 6 roles + 5 sub-roles
  - 7 production-grade public legal/info pages (Home, About, Contact,
    Privacy Policy, Terms & Conditions, Refund Policy, Delivery Policy)
  - 11+ Redux slices, real-time updates via Socket.IO, MongoDB Atlas storage
  - Cloudinary-backed image management with admin drag-to-reorder UI

Production-readiness verdict by area:
  - Storefront catalog .................. 9/10  Production-ready
  - Drops experience .................... 9/10  Production-ready
  - Cart & checkout ..................... 8/10  Manual-payment friction
  - Member account / wishlist ........... 8/10  Production-ready
  - Admin core CRUD ..................... 9/10  Production-ready
  - Admin marketing tooling ............. 5/10  Push-only, no email
  - Admin analytics ..................... 7/10  Strong charts, no funnels
  - Content management .................. 4/10  Hardcoded copy, no FAQ/size
  - Localization ........................ 2/10  LKR + English + LK only
  - Compliance posture .................. 6/10  No cookie banner, no a11y

Bottom line: the platform is fit for ~1,000 orders/month at its current scope.
Scaling to multi-region, multi-currency, multi-thousand-orders/month requires
the items listed in §6 (admin gaps) and §7 (public-page gaps).



================================================================================
2. PROJECT OVERVIEW
================================================================================

Brand
-----
Saga Elite positions itself as Sri Lanka's premier luxury streetwear house.
Voice is editorial ("Quietly made.", "Sent to ninety-three countries", "Hand
finished", "No restock"). The product cadence is "drops" — small numbered
chapters (DROP 01..DROP 0N) that go live for a limited window, sell what they
sell, then archive forever.

Audience
--------
  - Members-first: the brand pushes account creation hard via newsletter,
    "Join the Elite" CTAs, VIP early-access, and a multi-tier loyalty model
    (Standard → Elite → Rare → Legend → VIP).
  - Sri Lanka only: every checkout, shipping zone, currency display and
    delivery promise is LK-bound. The "Sent to ninety-three countries"
    marquee is brand storytelling, not literal current scope.

Business model
--------------
  - Drops: scheduled limited-edition releases with countdowns, member
    early-access, and post-launch archive
  - Always-on catalog: the standard product listing across Ladies / Gents /
    Unisex categories
  - Offers & Deals: flash sales, seasonal, clearance, aging-stock, tier
    discounts (admin can choose)
  - Mystery Gift hook: every order may include a surprise collectible item
    (Common / Rare / Epic / Legendary rarity), used as a brand-loyalty lever
  - Payments: manual bank transfer (Sampath Bank, Hatton, account
    108052612262, name N.Gayathree) is the primary path, with a 24-hour
    payment window. PayHere is the digital alternative.

Image sources
-------------
All hero / banner / category-logo images are uploaded via the admin
"Home Images" page and stored in Cloudinary. The admin can drag-to-reorder
them; client-side compression is applied at upload time.

Content sources
---------------
  - Hero slides + offers + category images + arrivals + trending + social
    images come from one consolidated API call: getLandingData()
  - Next-drop countdown comes from fetchUpcomingDrop()
  - Promise.all parallelizes the fetches; if either fails the page renders
    with empty arrays + a toast notification (no broken layout)

What the admin can already control
----------------------------------
  - Every image (hero, category, banner, logo)
  - Drop scheduling + active-drop selection
  - Hero eyebrow + headline copy (via SEO & Branding settings)
  - Brand stats (chapters, countries, hand-finished hours/piece)
  - Social URLs surfaced in footer + community block

What the admin cannot yet control (gap)
---------------------------------------
  - Manifesto body copy (hardcoded)
  - Drop-story narrative copy (hardcoded per drop type)
  - "Why Saga Elite" bullet content (hardcoded)
  - Testimonials curation (no admin UI to add/promote/order them)
  - Mystery Gift Spline scene swap (asset is hardcoded)

----------

trust artefact (after product detail). It is where customers verify "is this
brand real" before paying ~LKR 10–25k for a piece. Saga Elite handles the
narrative well — voice, founder presence, materials transparency — but the
admin cannot edit the narrative without a code deploy.

Gaps
----
  - Materials text is static; admin should be able to update sourcing copy
    when fabric origin changes
  - Founder bio is hardcoded; only photo URL is in shop-config
  - No timeline / journal section showing past drops or brand milestones
  - No press / awards grid (would help legitimacy)

────────────────────────────────────────────────────────────────────────────────

File:   Client-Side/src/pages/Legal/ContactPage.jsx  (910 lines)
Route:  /contact
Status: Production-ready

Sections rendered:

   1. Hero "Write to the atelier"
   2. Marquee — scrolling messaging strip
   3. Brand Moment — animated logo, "We read every note"
   4. Quick Channels (3-column cards):
        - WhatsApp (direct link, marketed as fastest)
        - Email (mailto, for longer notes / returns / wholesale)
        - Instagram DM
   5. Main Contact Form:
        - Name, email inputs
        - Subject pills: Order inquiry / Return request / Payment issue /
          General question / Press·Wholesale / Other
        - Message textarea (500-char max)
        - Atelier hours card alongside the form
        - Client-side validation: email regex + min-10-char message
        - Success/error toasts
   6. Atelier Address Ledger (location, phone, booking CTA)
   7. Social Links (Instagram, Facebook, TikTok)

Form behaviour
--------------
  Endpoint:  POST /contact  (relative to API_V1_URL)
  Payload:   { name, email, subject, message }
  On success: toast + form reset
  On error:   toast with fallback copy
  Persistence: stored server-side, surfaced in admin "Contact Inquiries"
               page with status workflow (new → in_progress → resolved →
               closed) and an admin-notes field

Channels presented to the customer
----------------------------------
  - WhatsApp     fastest                  link
  - Email        long notes, B2B          mailto
  - Instagram    social                   external link
  - Phone        copyable
  - Address      with map link

Hours (currently hardcoded — should move to shop config)
--------------------------------------------------------
  Mon–Fri:  09:00 – 18:00
  Saturday: 10:00 – 16:00
  Sunday:   Closed

Importance
----------
The Contact page is the operational SLA expectation-setter. Saga Elite
publishes WhatsApp as the "fastest" channel — that is a commitment, and the
admin Contact Inquiries queue is the operational backbone that fulfils it.
Strong setup; the only weakness is hours being hardcoded.

Enforcement
-----------
  Server middleware:  Server-side/Middlewares/admin-middleware.js
    - requireAdmin              gate for any admin role
    - requireSuperAdmin         super-admin only
    - requirePermission(name)   per-flag check; super-admins bypass

  Client guard:  PermissionGuard.jsx wraps every admin route
    - Super-admin bypass
    - Sub-admin checked against the route's required flag
    - Falls through to an Access Denied page with link back to dashboard

E. GLOSSARY
────────────────────────────────────────────────────────────────────────────────

  Drop                A scheduled limited-edition release (DROP 01..0N).
                      Goes live for a window, sells what it sells, then
                      archives. Admin schedules + manages inventory per drop.

  Mystery Gift        Surprise collectible item that may ship with an order.
                      Rarity: Common, Rare, Epic, Legendary. Configured by
                      admin in GiftManager, attached to drops or made global.

  VIP / Legend /      Customer membership tiers, ordered by lifetime value
  Rare / Elite /      and engagement. Drives early-access privileges, gift
  Standard            eligibility, and customer-tag filtering in admin.

  RMA                 Return Merchandise Authorization — the workflow
                      between a return request and a refund / restock.
                      Saga Elite does NOT have this; only manual WhatsApp
                      handling for defect/damage exchanges.

  AOV                 Average Order Value.
  LTV                 Customer Lifetime Value.

  Manual Payment      Saga Elite's primary payment path: customer transfers
                      to Sampath Bank account 108052612262 within 24 hours
                      and uploads proof; admin verifies in PendingPayments
                      queue, then order moves into Processing.

  PayHere             Sri Lanka's local payment gateway. Card alternative
                      to manual bank transfer.

  Atelier             Brand vocabulary for the workshop / studio. Used in
                      About + Contact ("write to the atelier").
