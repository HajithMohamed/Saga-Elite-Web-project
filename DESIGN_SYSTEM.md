

# Saga Elite - Design System & Developer Handoff

This document defines the production-ready Design System for Saga Elite. It serves as the bridge between the design tokens specified in Figma and our React + Tailwind CSS implementation. 

All components, variables, and interactions must adhere strictly to these guidelines to maintain Saga Elite's premium black (#0E0E0E) and gold (#F2CA50) luxury fashion identity.

---

## 1. Design Tokens (tailwind.config.js)

### Colors
Always use semantic color tokens rather than hardcoded hex values in components.
- `bg-primary`: `#0E0E0E` (Primary Background)
- `bg-background`: `#121212` (Secondary Background)
- `bg-surface`: `#1A1A1A` (Containers & Overlays)
- `bg-card`: `#202020` (Product/Feature Cards)
- `text-accent`, `bg-accent`: `#F2CA50` (Primary Gold)
- `border-border`: `rgba(255,255,255,.08)` (Subtle Dividers)
- *Status Colors*: `text-success` (#34C759), `text-warning` (#FFCC00), `text-error` (#FF453A).

### Typography
- **Font Families**: 
  - Headings/Display: `Playfair Display` (`font-display`, `font-serif`, `font-headline`)
  - Body/UI/Data: `Inter` (`font-sans`, `font-mono`, `font-body`)
- **Sizes (Desktop)**: 
  - `text-6xl` (Display XL)
  - `text-5xl` (Display L)
  - `text-4xl` (Heading XL)
  - `text-base` (Body)
  - `text-sm` (Body S)
  - `text-[13px]` (Caption)

### Spacing
Tailwind's default spacing perfectly mirrors our strict 4px grid requirement. **Never use arbitrary spacing values** (e.g. `[17px]`).
- `4px` (`-1`)
- `8px` (`-2`)
- `12px` (`-3`)
- `16px` (`-4`)
- `20px` (`-5`)
- `24px` (`-6`)
- `32px` (`-8`)
- `40px` (`-10`)
- `48px` (`-12`)

### Radius
- `rounded-sm`: 8px
- `rounded-md`: 12px
- `rounded-lg`: 16px
- `rounded-xl`: 20px
- `rounded-xxl`: 24px
- `rounded-full`: 9999px (Pill)

## 2. Layout & Auto Layout (Flex/Grid)

### Grid Specifications
Use Tailwind's Grid system to build responsive layouts matching the Figma specifications:
- **Desktop (1280px+)**: `grid-cols-12`, max-width `1280px`, gap `32px` (`gap-8`).
- **Tablet (768px+)**: `grid-cols-8`, gap `24px` (`gap-6`).
- **Mobile (<768px)**: `grid-cols-4`, gap `16px` (`gap-4`).

### Auto Layout Constraints
- **Never manually position repeated elements** (avoid `absolute` unless strictly necessary for overlays/badges).
- Use `flex flex-col` for vertical stacking and `flex items-center gap-X` for horizontal alignment.
- **Images**: Ensure all images scale proportionally using `object-cover` or `object-contain` within a fixed aspect ratio container (e.g. `aspect-[4/5]`).

## 3. Motion & Microinteractions

Animations must feel **Fast, Smooth, Natural, Purposeful, and Elegant**. 

### Global Animation Timing
- **Page Transitions / Modals**: 300-400ms (`duration-300`).
- **Hover States**: 200ms (`duration-200 ease-out`).
- **Scroll Reveals**: 500ms (`duration-500 ease-in-out`).
- **Hero Slider Crossfade**: 700ms (`duration-700`).

### Component Motion Guidelines
- **Product Cards**: On hover, scale container to `scale-103` and zoom image to `scale-105` over `500ms`.
- **Buttons**: On hover, apply `-translate-y-[2px]` and increase shadow.
- **Countdowns**: Use `Framer Motion` `AnimatePresence` with `mode="popLayout"` for smooth number flipping (400ms duration).

---

## 4. Accessibility Rules

### Touch Targets & Usability
- **Minimum Touch Target**: Any clickable element (icon, button, link) on mobile MUST be at least `48x48px`.
- **Aria Labels**: All icon-only buttons (Search, Cart, Menu, Wishlist) must have descriptive `aria-label` tags.

### Loading States
- **NEVER use only a spinner.** 
- Always use the `<Skeleton>` component (`src/components/ui/skeleton.jsx`) to create a layout-accurate shimmer effect (`animate-pulse`) before content loads.

### Empty States
- **Never leave blank screens.**
- If a Cart, Wishlist, or Search yields no results, render an Empty State component with a clear Call to Action (e.g., "Continue Shopping").

## 5. Developer Notes by Component

### Hero Carousel
- **Responsive Height**: Hardcoded breakpoints in `LandingSections.jsx` (`h-[680px]` down to `h-[480px]`).
- **Auto-play**: 6 Seconds.
- **Motion**: `700ms` Crossfade, `1.05x` Parallax scale over 6 seconds.

### Mobile Bottom Navigation
- **Visibility**: Only visible below `md` breakpoint (`hidden md:flex`).
- **Behavior**: Sticky to the bottom, uses a dark glassmorphism backdrop (`bg-black/80 backdrop-blur-md`).
- **Safe Area**: Must account for iOS home bar padding.

### Footer
- **Desktop**: 4-column Grid layout.
- **Mobile**: Accordion style to save vertical space.
