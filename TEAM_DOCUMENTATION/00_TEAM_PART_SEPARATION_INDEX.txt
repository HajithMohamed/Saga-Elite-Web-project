Main Project Architecture
-------------------------
The system is a MERN stack ecommerce platform for Saga Elite, a limited-edition
fashion brand. The application is split into:

Frontend:
Client-Side/
React, Vite, Redux Toolkit, React Router, Tailwind CSS, Framer Motion,
Socket.io client, Axios, Lucide icons, Three/Spline visual support.

Backend:
Server-side/
Node.js, Express, MongoDB/Mongoose, Socket.io, Cloudinary, Nodemailer,
JWT authentication, rate limiting, request validation and scheduled jobs.

Database:
MongoDB collections are modeled through Mongoose models in Server-side/Models.
Important collections include User, Guest, Product, Drop, Order, ManualPayment,
Gift, Image, Banner, Category, Notification, Review, Coupon, Offer, SiteConfig,
AdminLog, SmartAlert and Recommendation.

Real-time:
Socket.io is initialized in Server-side/server.js and shared through
Server-side/Utils/socket-service.js. The frontend connects through
Client-Side/src/lib/socket.js and uses SocketBridge plus useSocketEvent hooks.


Common Middleware Used Across The Project
-----------------------------------------
auth-middleware.js
Verifies JWT from Authorization header or cookie, loads the user from MongoDB,
rejects inactive users and attaches req.userInfo.

optional-auth-middleware.js
Loads the user if a valid token exists, but allows public users to continue.
Used for public product/drop pages where personalization is optional.

admin-middleware.js
Provides requireAdmin, requireSuperAdmin and requirePermission. Used to protect
admin routes and permission-based operations.

request-validation.js
Central validation and sanitization layer for auth, product, drop, order,
payment, image, review, notification, admin, cart, wishlist, coupon, offer and
shipping requests.

admin-log-middleware.js
Writes successful admin POST, PUT, PATCH and DELETE actions into AdminLog.

pagination-middleware.js
Adds product pagination, category filtering, variant filtering, price filtering,
stock filtering, search and sorting.

multer-middleware.js
Handles image uploads and receipt uploads in memory. Allows images globally and
allows PDF for payment receipt proof.

guest-tracking-middleware.js
Creates or reuses a guestToken cookie and attaches req.guestToken.

maintenance-mode.js
Reads SiteConfig maintenance settings and can temporarily block public traffic.

rateLimitinMiddleware.js
Defines loginLimiter, authLimiter, generalLimiter and contactLimiter.

customMiddleware.js
Adds request logging through Winston.

versioningMiddleware.js
Contains URL version check logic for API versioning support.


Common Admin Flow
-----------------
1. Admin logs in through the auth system.
2. JWT is saved through cookie/local token flow.
3. Frontend App.jsx calls checkAuthAction.
4. CheckAuth protects admin routes.
5. AdminLayout renders sidebar, header, global search and notifications.
6. PermissionGuard checks frontend route permission.
7. Backend route checks authMiddleware and requireAdmin/requirePermission.
8. Request body is validated through request-validation.js.
9. Controller performs the database operation.
10. admin-log-middleware records mutating admin actions.
11. Socket events update admin badges, dashboards and real-time panels.


Common Shopping Flow
--------------------
1. Customer opens homepage.
2. Home.jsx loads landing data from banners, hero images, products, drops,
   offers and deals.
3. Customer browses product listing or drop pages.
4. Product listing filters use query params and backend pagination/filtering.
5. Product detail loads product, variants, images, reviews and suggestions.
6. Customer adds item to cart or wishlist.
7. Checkout creates an order and deducts stock inside backend order logic.
8. Payment can be manual bank transfer, card/sample payment or other configured
   method.
9. Notifications are sent by email, web notification and sometimes WhatsApp.
10. Admin verifies payment and updates order status.
11. Customer tracks order and can review products after delivery.
